# makefun-forecast-city

One line of weather forecast (132 characters) for a city that does not exist — Mirrortown — written for the make.fun competition **Charm the Commuter: Forecast a City That Isn't**.

## The entry

> Mirrortown: thick fog, 9°C, buses 4 minutes late, visibility 20 metres — your reflection in the window already got off at your stop.

## How it runs

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness, no clock) writes the line to `/output/entry.txt`:

```sh
node main.ts
```

Run it twice and the output is byte-identical.
